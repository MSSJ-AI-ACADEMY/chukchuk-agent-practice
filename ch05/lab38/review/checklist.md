# 아침 브리핑 검수 체크리스트

각 항목마다 한 줄로 답한다.
형식: [통과] 또는 [문제] 항목 - 근거(원문 인용, 파일 경로)

1. 출처: 메모별 요약 항목마다 [파일명]이 있고,
   소식마다 [출처 이름](주소)가 있는가
2. 사실: 원본 메모에 없는 내용(날짜, 숫자, 주소, 인물)이 섞였는가
3. 중복: 같은 내용이 두 번 이상 들어 있는가
4. 날짜: 제목의 날짜가 오늘 날짜이고,
   본문의 날짜가 원본 메모와 일치하는가
5. 불확실 표기: 확실하지 않은 내용에 [확인 필요]가 붙어 있고,
   소식이 5개 미만이면 이유가 '## 확인하지 못한 것'에 있는가

마지막 줄에 "종합: 통과" 또는 "종합: 문제 N건"을 적는다.
